## 三、可以暂不实现的内容

- 真实 Browser/Computer Use/Realtime Voice 控制；
- Kubernetes 级别调度和多节点 Event Bus；
- 完整 OAuth Provider、Plugin 市场和微虚拟机沙箱；
- 真实向量数据库和生产级 Artifact Object Store。

这些内容在正文中保留架构边界和生产要求即可，不在无依赖教学工程中伪实现。

## 四、完成标准

- 每个 MUST 项都有正文说明、可运行代码或明确的协议边界；
- Python/TypeScript 示例在相同输入下具有一致的终态和错误语义；
- 评估报告能同时检查最终结果和 Tool/Policy/预算轨迹；
- A2A/Artifact 不绕过 Agent Host 的身份、Policy、Checkpoint 和 Trace；
- MkDocs 严格构建、内部链接、Mermaid、Python 和 TypeScript 测试全部通过。

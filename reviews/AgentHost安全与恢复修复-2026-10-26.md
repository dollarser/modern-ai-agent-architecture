| 原始反例 | 修复后的行为 | 回归测试 |

| Registry 快照共享参数 Schema | 每 Run 深复制 Schema | Python / TS 注册后修改原 Schema |

## 仍需生产集成

- 本地派发标记不是下游执行回执。超时停止等待后，线程、Promise 或外部请求仍可能产生副作用；恢复阻断不会撤销已提交操作。应用必须核对状态，本示例没有自动对账或人工补录 API。
- 没有外部幂等事务、Outbox、跨进程锁、租约或 fencing token；JSON 原子替换也不构成跨文件事务或断电持久性保证。
- 工具代码摘要不覆盖闭包配置、默认值、传递依赖、callable 对象状态或远端实现；维护者须更新显式实现版本。自定义 Policy 须更新规则版本。
- Schema 是文档列明的教学子集；完整 MCP Schema 需要标准校验器。遇到不支持的约束时拒绝接入，不默默放宽。
- 随机临时文件处理预建链接，工作区路径检查仍不隔离恶意进程并发替换目录。固定测试 argv 也不会限制测试代码的系统权限。需 OS/容器隔离及进程树回收。
- 快照格式变化后，旧 Checkpoint 不能静默恢复；应保留旧数据并显式迁移或创建新 Run。
